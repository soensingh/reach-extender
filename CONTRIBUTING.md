# Contributing

Thanks for helping make Reach Extender better.

Reach Extender is **closed source**. This repository holds the README, release downloads, the changelog and the community spaces, but not the app's code. That means the most useful things you can send are bug reports and ideas.

## Report a bug

1. Make sure you're on the latest version from [Releases](https://github.com/soensingh/reach-extender/releases/latest).
2. Search the [open issues](https://github.com/soensingh/reach-extender/issues) in case someone already reported it. If they did, add a thumbs-up reaction or any new details there.
3. Open a [bug report](https://github.com/soensingh/reach-extender/issues/new?template=bug_report.yml) and fill in the form. The most helpful details:
   - the app version (Finder → Applications → Reach Extender → Get Info), your macOS version and your Mac model;
   - which screen-sharing or recording app you were using, if any;
   - exact steps, what you expected and what happened;
   - a screenshot or short screen recording.

## Suggest an idea

Post it in [Discussions → Ideas](https://github.com/soensingh/reach-extender/discussions/categories/ideas). Upvote the ideas you'd like to see, too. The pinned **Roadmap** discussion shows what's planned.

## Ask a question

Use [Discussions → Q&A](https://github.com/soensingh/reach-extender/discussions/categories/q-a).

## Purchase, license or refund problems

Email **soensingh@gmail.com**. Please **never post license keys, receipts or payment details** in issues or discussions. Anyone can read them.

## Security problems

Report them privately as described in [SECURITY.md](SECURITY.md).

## Pull requests

Because the code isn't here, pull requests are limited to **documentation fixes**: typos, broken links and unclear wording in this repo's Markdown files. Please open an issue first for anything bigger.

By sending a pull request you agree that it can be used as described in [LICENSE](LICENSE), section 5.

## Be kind

Everyone taking part here is expected to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
